# Contributing

Thanks for helping out.

1. Fork the repo and create a branch (`git checkout -b my-change`).
2. Keep changes small and focused. The app is plain Java with no external dependencies; please keep it that way.
3. Push your branch. The **Build debug APK** workflow runs on every push; it must pass.
4. Open a pull request and describe what you changed and which device (phone or TV box, Android version) you tested on.

When reporting a bug, please include the Android version, the device or TV box model, your Termux version and the exact message the app shows.
